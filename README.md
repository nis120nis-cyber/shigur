# שיגור 🚀

מעלים קבצים, מקבלים אתר אמיתי עם קישור ציבורי.

- מעלים קובץ HTML, קובץ ZIP של אתר שלם או תיקייה שלמה
- בוחרים כתובת, למשל `/s/my-site/`
- כל אחד יכול לפתוח את הקישור, גם בלי חשבון
- אפשר לעדכן אתר קיים (אותה כתובת) או למחוק אותו
- מתחברים עם גוגל, GitHub או Microsoft (את השניים האחרונים מפעילים בעמוד הניהול). כל אחד מנהל רק את האתרים שלו. עד 2 אתרים חדשים בכל 4 חודשים למשתמש
- המנהל רואה את כל האתרים ויכול לחסום משתמשים
- **✨ שיפור אוטומטי בהעלאה**: מתקן תצוגה בטלפון, עברית ו-RTL, מוסיף תצוגה מקדימה לוואטסאפ ומזהיר על קבצים חסרים
- **📊 סטטיסטיקות** צפיות לכל אתר (בלי בוטים), ו**שיתוף בוואטסאפ** בלחיצה
- **מסד נתונים לכל אתר**: תגובות, שיאים, לייקים וטפסים בשורת קוד אחת. תיעוד בכתובת `/docs`
- מאובטח: אימות גוגל בצד השרת, עוגיות חתומות, הגנת CSRF, ובידוד מלא של האתרים המתארחים. פירוט ב-[SECURITY.md](SECURITY.md)

רץ על Cloudflare Workers + KV, בחינם.

## העלאה לאוויר

1. ב-Cloudflare: **Workers & Pages** ← **Create** ← **Import a repository** ← `shigur` ← **Deploy**.
2. ב-[Google Cloud Console](https://console.cloud.google.com) יוצרים **OAuth Client ID** מסוג Web application, ומוסיפים ב-**Authorized JavaScript origins** את כתובת האתר (`https://shigur.<השם-שלכם>.workers.dev`).
3. מדביקים את ה-Client ID ב-`GOOGLE_CLIENT_ID` בקובץ `wrangler.jsonc` ודוחפים ל-GitHub. האתר מתעדכן לבד.

## מגבלות
- אתרים מתארחים רצים בארגז חול, ולכן localStorage ו-cookies לא זמינים בהם (במקומם יש את מסד הנתונים)
- מסד נתונים: 4KB לרשומה, 10,000 רשומות לאתר, 20 כתיבות בדקה למבקר
- עד 50MB ועד 500 קבצים לאתר, ועד 24MB לקובץ בודד
- בתוכנית החינמית של Cloudflare: עד 1,000 שמירות קבצים ביום (כל קובץ באתר נחשב שמירה אחת) ו-100,000 צפיות בקבצים ביום
